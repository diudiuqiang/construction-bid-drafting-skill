# 参考资料甄别规则

## 0. 核心原则：抽骨不抽肉

参考项目标书（别的工程、别的地点、别的规模）**只能借骨架，不能抄肉**。

- **骨**：章节结构、写作顺序、表格类型、方案论证的逻辑链、资源配置的核减方法。
- **肉**：项目参数、地质水文、设备型号、工程量、工期、报价、人员姓名、现场描述。

一句话：**结构可以照搬，内容必须重写。**

## 2. 整章删除的判断

参考标书里有些章节对本项目完全不适用，直接删：

- 参考项目有「储能系统施工方案」而本项目无储能 → 整章删；
- 参考项目是「屋顶分布式」而本项目是「渔光互补水面」→ 屋顶作业章节删或改写；
- 参考项目有「送出线路 220kV」而本项目是 10kV 全额上网 → 按本项目重写。

删之前先对照本项目的《章节骨架模板.md》和《合规红线与硬指标.md》，确认该章节不在硬指标里。

## 3. 三个坑（踩过的）

### 坑一：规范清单全废

参考标书的规范清单可能是**另一个行业/地区**的，甚至混着已废止版本。

**不要抄规范清单**，一律以本项目 conf/ 里的规范清单为准（见《写作基准模板.md》第 5 节）。

体检脚本会扫 2008 年以前的版本号（白名单除外），但扫不出「引错行业规范」，必须人工核。

### 坑二：项目参数全串

参考项目的「XX 兆瓦」「XX 公里」「XX 台」会**成串出现在正文、表格、方案里**。

只改正文不改表格，是最常见的翻车方式。

替换后必须全局搜索参考项目的特征数字（MW 数、kV 等级、地名、设备型号）。

### 坑三：编号错乱

参考标书的表号/图号是它自己的（它的表 3-1 可能是「施工总平面」，而本项目表 3-1 是别的）。

**绝对不要保留参考标书的编号**，一律走本 skill 的两遍法编号
（`plan_numbers` / `apply_numbers`），否则合并后编号撞车或缺号。

## 4. 什么情况借参考、什么情况用自己的判断

| 情况 | 处理 |
|---|---|
| 参考与本项目同类型（渔光互补/农光/水面） | 骨架可借，参数必换 |
| 参考是地面集中式 / 屋顶分布式 | 只借通用章节（采购、项目管理、保修），方案章节重写 |
| 参考的规范清单 | 不用，用本项目 conf |
| 参考的资源配置数字 | 不用，按《资源配置核减方法.md》重算 |
| 参考的「重难点分析」写法 | 借逻辑链（工况→风险→对策→验证），内容重写 |
| 参考的保修/响应时限承诺 | 借承诺结构，数值用本项目前附表要求 |
| 参考的应急预案 | 借结构（组织→预警→处置→物资），本项目工况重写 |
| 参考的文明施工/环保措施 | 借条目框架，标准用本项目属地要求 |

## 5. 拿不准怎么办

按《写作基准模板.md》第 3 节的「决策记录」格式记下来，挂〔初稿注〕，
交给有施工经验的人判断。**不要自己拍脑袋写死**——涉地勘终值、设计未形成的内容尤其如此。

## 6. 参考素材的四个来源分级

| 级别 | 来源 | 用法 |
|---|---|---|
| 一级（可直接信） | 招标文件、前附表、图纸、勘察报告、疑问答复 | 原文抄录，不改写 |
| 二级（需换算） | 行业通用规范、标准图集 | 引编号 + 本项目参数 |
| 三级（仅借结构） | 同类项目标书 | 抽骨不抽肉 |
| 四级（仅启发） | 网络文章、AI 生成内容 | 只借逻辑，事实必须核 |

**三四级来源里的具体数字一律不可直接采用。**
