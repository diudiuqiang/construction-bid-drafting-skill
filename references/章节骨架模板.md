## 2 各节内容要点

### 3.1 施工部署

| 子节 | 内容要点 | 硬指标 |
|---|---|---|
| 3.1.1 编制依据、执行标准与工程概况 | 规范清单 + 工程概况 + 招标响应口径 + 总体目标 | **无已废止规范**；含行业/属地专项依据 |
| 3.1.2 施工区段划分与施工总平面布置 | 区段划分 + **八要素**（道路/堆场/临电/消防/临水/办公/生活/危险品仓库）+ 边界方案 + 临电临水计算 | 八要素齐全；**满足高峰期** |
| 3.1.3 施工组织方案与主要分部分项施工方法 | 流水段 + 工艺选择 + 各分部分项施工方法 | 规范符合性对照表 |
| 3.1.4 施工总进度计划与进度控制 | 里程碑 + 网络图 + 横道图 + 关键线路分析 + 控制措施 | **关键线路标示清晰【双重】** |
| 3.1.5 项目运维方案与保证发电效率方案 | 运维组织 + 发电效率保障措施 | 与保修期衔接 |
| 3.1.6 前期手续配合协调方案 | 手续清单 + 与发包人/属地主管部门配合 | — |
| 3.1.7 施工部署与现场实际工况匹配性说明 | 实景锚点校核 | 防「与现场实际工况不匹配」 |

**八要素速查**：施工道路 / 材料堆场 / 临时用电 / 消防 / 临水用水 / 办公区 / 生活区 / 危险品仓库。
> 缺一个就是「要素不全」。高峰期满不满足要看**同一时间**的人数与机械峰值。

### 3.2 施工重难点技术方案

| 子节 | 内容要点 | 硬指标 |
|---|---|---|
| 3.2.1 重难点识别与可操作对策 | 逐项识别 + 对策可操作（不写空话） | 对策必须可落地 |
| 3.2.2 特殊气候施工方案 | 高温/冬季/雨季/台风（按项目所在地裁剪） | 台风、梅雨、汛期 |
| 3.2.3 重大危险源识别与应急预案 | 辨识清单 + 五类预案（起重/火灾/触电/水上/机械） | **无漏项** |
| 3.2.4 危大工程识别及管理措施 | 危大工程清单 + 专项方案编制论证 | **危大工程清单** |
| 3.2.5 质量管理体系、控制措施及验收标准 | 质量责任制 + 三检制 + 验收标准 + 检测调试 + 资料移交 | **无已废止规范** |
| 3.2.6 支架安装专项施工方案 | 安装工艺 + 精度控制 + 作业平台通道 + 防腐 | 「全面」 |
| 3.2.7 属地专项建设要求 | 属地标准响应 + 环保/农业要求 + 保产协调 | **含尾水【双重】** |
| 3.2.8 专项技术方案 | 本项目特有的技术替代方案（如不设避雷针的防雷替代） | 与参考资料做法相反处必须改写 |
| 3.2.9 通用安全文明施工环保水保 | 安全体系 + 文明施工 + 环保水保 + 智能化监控 | 与 5.1.2 体系层去重 |

> **去重铁律**：3.2.9 是「现场执行层」，5.1.2 是「体系层」。同一内容两处都写 → 被判「繁复堆砌」。
> 分界线：**执行层写「怎么做」，体系层写「谁负责、按什么制度」。**

### 3.3 施工资源配置

| 子节 | 内容要点 | 硬指标 |
|---|---|---|
| 3.3.1 关键工序资源配置计划 | 桩基/支架组件/电气安装三关键工序的资源匹配 | 合理 |
| 3.3.2 拟投入主要施工机械配置 | 型号 + 数量 + **年份** + 进场时间 | **年份字段** |
| 3.3.3 劳动力投入计划 | **按自然月** + 各工种人数 + **高峰总人数** | **按自然月 / 各工种 / 高峰总人数** |
| 3.3.4 周转材料与主要材料储备方案 | 储备量 + 进场安排 | 储备充足 |
| 3.3.5 资源配置与进度计划匹配性总校核 | 三项校核汇总 | — |

> **资源配置是「不合理」判定的高发区**。常见错误是照抄参考项目的劳动力数量（例如光伏安装给到 150+ 人）。
> 详见《资源配置核减方法.md》。

### 4 采购

### 8 保修响应时限与质保金扣罚承诺

| 子节 | 内容要点 | 硬指标 |
|---|---|---|
| 8.1 响应机制 | 到达现场时限 + 解决问题时限 | **12 小时 / 24 小时** |
| 8.2 扣罚承诺 | 未满足**任一条件**的扣罚金额 | **任一条件 + 金额（原文）** |
| 8.3 响应流程、记录与闭环 | 流程图 + 记录 + 闭环 | — |

> 写成「及时到场」就是硬伤——**时限和金额是承诺，不是描述**。

## 5 正文生成顺序（推荐）

1. 锁定项目参数字典与现场事实 → 写入 `_写作基准.md`
2. 按本骨架重建连续编号（**不继承参考资料的混乱编号**）
3. 抽通用骨架并按八元组全量替换
4. 删不适用整章，跑正则零残留校验
5. 新写本项目专项
6. 每章至少 1 句实景锚点，控制「繁复堆砌」
7. 逐条对照覆盖度自检表自评

> **顺序很重要**：先锁参数再写正文。参数没锁就开写，写到一半发现容量/桩型变了，全篇返工。
