# 写作基准模板

> **用法**：开工前把本模板复制到项目工作目录，命名 `_写作基准.md`，逐项填实。
> 填实后的文件是分章编写的唯一口径来源，**不得写入标书正文**。
> 填不实的格子**不要留空**——写「待确认」并挂 `〔初稿注〕`，或列为待澄清事项。
> 成稿后按第 6 节跑零残留校验，按第 7 节登记参考资料用法。

---

## 0 先想清楚三件事

在动笔写基准之前，先回答三个问题。答不上来的，基准一定写不好。

| 问题 | 为什么必须先答 | 答不上来的后果 |
|---|---|---|
| 评标办法是什么？技术标打分还是合格制？ | 决定全篇写法：打分制要「多点得分项」，合格制要「零硬伤、无无关内容」 | 合格制下堆砌无关内容 → 直接不通过 |
| 通过标准原文是哪几句？ | 这是自检表的唯一来源，逐条映射到章节节点 | 自检表凭印象写 → 漏掉硬指标 |
| 本项目有哪些「别的项目没有」的工况？ | 实景锚点全靠它，也是「与现场实际工况相匹配」的证据 | 通篇通用工艺 → 被判「与现场实际工况不匹配」 |

> **合格制项目的三条铁律**：① 无与本项目无关内容；② 须与现场实际工况相匹配；③ 不存在明显不合理或过于简单粗略（或过于繁复堆砌）。
> 这三条是**否决项**，不是评分项。一处硬伤即不通过，且不能靠事后澄清补救。

## 1 项目身份（唯一可写入的事实）

> **原则**：正文只能出现本表中的项目参数。表外数值一律不得出现。
> 「唯一可写入」意味着：没写进本表的容量、电压、桩型、工期、人数，正文里出现了就是串稿。

| 项 | 值 | 来源 |
|---|---|---|
| 项目名称 | | 招标文件 |
| 招标人 / 发包人 | | 招标文件 |
| 建设地点 | | 招标文件 / 可研 |
| 容量 | 直流侧 ___ MWp / 交流侧 ___ MW | 可研 |
| 主要设备 | 组件 ___ Wp ___ 型 ___ 块；逆变器 ___ kW ___ 台；箱变 ___ kVA ___ 台；___ 个发电单元 | 可研 / 设计 |
| 支架基础 | 固定/可调支架 ___° 倾角 / ___° 方位角；___ 桩型，桩长 ___ m | 可研（暂估需标注） |
| 布置 | 组件高于水体常年水位 ___ m；立柱列间距 ≥ ___ m、行间距 ≥ ___ m；前后排间距 ___ m | 设计 |
| 电气 | ___ kV ___ 上网；新建 ___ 座；___ 回集电线路；接地电阻 R ≤ ___ Ω | 可研 |
| 自然条件 | 地基 ___；抗震设防 ___ 度 / ___ g；风荷载 ___ kN/m²（___ 年一遇）；气候 ___ | 地勘 / 可研 |
| 防雷 | 方阵内 ___ 避雷针/避雷线；以 ___ 替代 | 设计 |
| 储能 | 配置 / **不配置**（明确写死，避免歧义） | 招标文件 |
| 工期 | ___ 日历天（含并网 / 不含并网，明确） | 招标文件 |
| 保修 | ___ 年；___ 小时内到达现场、___ 小时内解决问题，未满足任一条件扣质保金 ___ 元 | 招标文件 |
| 评标 | 澄清低价法 / 综合评估法；技术标 ___（合格制/打分）；前附表 ___ 允许偏差 / 不允许偏差 | 招标文件 |

**填写要点**：
- 容量、电压、桩型、工期这四项**最容易串稿**，必须逐字核对招标文件。
- 「不配置储能」这类否定项要显性写出——写了「不配置」反而安全，不写才会被误读。
- 保修条款里的数字（12h / 24h / 任一条件 / 金额）是硬指标，必须原文抄录，不得四舍五入或改写。

## 2 现场事实（已踏勘确定，只能照此写，不得补充数值）

> **原则**：本组事实是「与现场实际工况相匹配」的直接证据。
> 每条都应能在正文里找到对应锚点。**不得自行补充踏勘未确认的数值**（水深、水位、承载力、单塘尺寸等）。

| # | 事实 | 正文落点（哪个章节会用到） |
|---|---|---|
| 1 | 场地形态：___ | |
| 2 | 场界与出入口：___ | |
| 3 | 场地与场外道路高差：___ | |
| 4 | 水体/鱼塘分布：___ | |
| 5 | 水面漂浮物/水草情况：___ | |
| 6 | 塘间通道承重：人可走 / **不可走机械** | |
| 7 | 既有建筑物：___ | |
| 8 | 既有道路：___ | |
| 9 | 既有管线/电杆：___ | |
| 10 | 材料进场路线：___ | |

**填写要点**：
- 第 6 条「不可走机械」这类**限制性事实**极其重要——它直接决定机械选型和施工方法，也是「不合理」判定的反向证据。
- 每条事实后面写「正文落点」，防止写完后正文里找不到锚点。

## 3 决策记录（覆盖此前口径，优先级最高）

> **原则**：本表记录业主/领导/编制人的临时决策，**优先级高于任何参考资料和旧大纲**。

**常见决策类型**（供对照，不一定是你的项目会遇到）：

| 类型 | 典型冲突 | 处理方式 |
|---|---|---|
| 围墙/围蔽 | 「不设围墙」vs 属地「封闭式=不可透视」规范 | 明确「不处理、保持现状」，仅配管理措施，**不做合规论证、不列待澄清** |
| 既有电杆 | 「需加固」vs「状况良好」 | 保持现状、不加固，仅做复测/警示/避让/停电配合 |
| 勘察/设计未形成 | 按可研参数写实 vs 无地勘数据 | 写「可研暂估值/假定条件」+ 挂初稿注，**不得虚构数值** |
| 疑问未答复 | 列为待澄清 vs 按编制人理解写定 | 写定一套完整方案，不写备选、不写问句；在说明文件里标注待反馈 |

> **关键判断**：决策 1、2 属于「**收窄**」——删掉原大纲里的一大段工艺内容。
> 收窄比扩写安全：合格制下，「写了不该写的」是硬伤，「没写」往往只是扣分项。
> 但收窄必须**留痕**（在本表记录），否则后续编写人不知道删过什么，会再写回来。

## 4 禁用内容（合格制红线：无与本项目无关内容）

> **原则**：成稿后对全篇跑正则，**零残留**才算通过。
> 禁用词分三类：① 其他项目的地名/项目名；② 其他项目的容量/电压/设备特征；③ 本项目明确不做的工艺/系统。

### 4.1 禁用词表（写入 `conf/禁用词.txt`，每行一条，`#` 开头为注释）

```
# 格式：每行一个词，正则匹配，命中即红线
# 示例（换成你的项目）：
其他项目地名|其他项目名|其他招标人名
其他项目容量（如 20MW、70MW、100MW）
其他项目电压等级（如 220kV、110kV、35kV）
本项目不做的系统（如 储能|SVG|主变|风电升压站）
本项目不做的工艺（如 钻孔灌注桩|清淤|微型桩）
其他项目的日期、图纸编号、人名、机构名
```

### 4.2 已废止规范（硬红线）

**严禁出现任何 2008 年以前的旧版规范号**。常见废止版号：

```
GB50204-2002 | GB50300-2001 | GB50202-2002 | JGJ79-2002 | GB50203-2002
GB50168-2006 | GB50169-2006 | GB50171-1992 | GB50150-2006 | GB50303-2002
GB50057-1994 | GBJ147-1990 | GB/T19939-2005 | GB/Z19964-2005 | DL5009.3-1997
```

> **例外**：个别规范确实现行有效（如 JGJ 46-2005），须**写明理由**并加入白名单。
> 判定方法：上「全国标准信息公共服务平台」查现行状态，不要凭记忆。

### 4.3 其他项目特征

- 其他项目的**人名、机构名、图纸编号、机械型号数量表、进度表、地名、容量、电压等级**——一律不得出现。
- 参考素材里的表格**不能直接复制**，表头、数据、单位都要重做。

## 5 规范清单（只用有把握的现行版号）

> **原则**：写不准编号的规范，**只写名称并注明「现行有效版本」**，不要凭记忆写编号。
> 全篇声明：「本方案采用国家及上海市现行有效标准，无已废止规范；投标截止日前如有更新，以最新现行版为准。」

### 5.1 通用必引（按项目类型裁剪）

| 类别 | 规范 |

| 施工质量验收统一 | GB 50300-2013 |
| 地基基础 | GB 50202-2018 |
| 混凝土结构 | GB 50204-2015 |
| 钢结构 | GB 50205-2020 |
| 砌体结构 | GB 50203-2011 |
| 电缆线路 | GB 50168-2018 |

| 盘柜及二次回路 | GB 50171-2012 |
| 电气交接试验 | GB 50150-2016 |
| 建筑电气 | GB 50303-2015 |
| 现场供用电安全 | GB 50194-2014、JGJ 46-2005 |

### 5.2 行业/属地专项（按项目所在地补充）

- 行业专用规范（如光伏：GB 50794-2012、GB/T 50795-2012、GB/T 50796-2012、GB 50797-2012；水面光伏：NB/T 10100）

## 6 写作风格与格式（分章统一）

### 6.1 文体

- 正式标书书面语，**第三人称、陈述句、可操作**。
- 禁止口语；禁止「本公司曾经/在某项目」等案例叙述（这是打分制写法，合格制下属于「无关内容」）。
- 禁止「依据/现场/复用/必附」这类括注——那是大纲的自检标记，**不是标书内容**。

### 6.2 实景锚点

- **每章至少 1 句本项目实景锚点**，落到第 1 节参数或第 2 节现场事实。
- 作用：证明「与现场实际工况相匹配」，同时防止通篇通用工艺被判「过于繁复堆砌」。
- 反面例子：通篇「本工程桩基采用静压沉桩」——哪个工程？什么地质？没有锚点就是模板。

### 6.3 层级与编号

- 层级严格按大纲编号 `3.1 / 3.1.1 / 3.1.1.1 …`。
- Markdown 用 `##` `###` `####` 对应（`#` 只用于封面/横幅）。
- **Markdown `#` 级数才是逻辑层级**，编号深度不可靠（有的章节用 3.1/3.1.1，有的用 4/4.1，同一深度分属不同层级）。

### 6.4 表格与图

- 表格用 Markdown 表格，**表名写「表 X-X …」**，放在表格上方。
- 图用「图 X-X …（另册附图）」占位，**不要画 ASCII 图**。
- 表名可能加粗（`**表 3-19 …**`），与表格之间可能隔空行和「注：…」行——自检脚本要能识别。

### 6.5 数字与不确定值

- 数字与量词必须准确。
- 不确定的数值写「按可研暂估」「按发包人确认后执行」，**不得杜撰**。
- `〔初稿注：…〕` 只在依赖勘察/设计成果、或需投标小组反馈处使用，**全篇控制在 10 处以内**。

### 6.6 硬指标必须显性写出

以下硬指标**必须在正文里显性出现**，不能靠读者推断：

| 硬指标 | 说明 |
|---|---|
| 无已废止规范 | 全篇声明 + 规范清单核对 |
| 总平面八要素满足高峰期 | 道路/堆场/临电/消防/临水/办公/生活/危险品仓库 |
| 关键线路标示清晰 | **双重出现**（进度章节 + 网络图说明） |
| 危大工程清单 | 独立清单，不得缺项 |
| 机械配置表含年份 | 型号/数量/**年份**/进场时间 |
| 按自然月劳动力 | 各工种人数 + **高峰总人数** |
| 高标准鱼塘含尾水 | **双重出现**，属地要求 |
| 设备五要素 | 质量标准/技术性能/验收标准/质保期/技术服务 |
| 材料进场四字段 | 名称/规格/数量/时间 |
| 人员资格证书有效期内 | 关键岗位证书 |
| 保修 12h/24h/任一条件/金额 | 原文抄录 |

### 6.7 条件性表述

- **不写**任何「备选方案」「如招标人要求则…」「是否…待定」。
- 合格制 + 不允许偏差 = 条件性表述本身就是偏差。
- 需要说明的内容写成「自备解决方案 + 费用工期已含入报价」，写成**履约安排**而不是问句。

## 7 参考素材来源与用法

> **原则**：参考资料分「可抽工艺」和「必须替换」两类。
> 每份资料登记：**性质 / 可抽什么 / 必须删什么 / 用法**。

| 素材 | 性质 | 可抽 | 必须删/替换 |
|---|---|---|---|
| | | | |

### 7.1 抽骨不抽肉

- **大段复用**：通用工艺工法、管理体系、安全文明、调试验收等**与项目无关的文字骨架**。
- **全量替换八元组**：项目名 / 招标人 / 地名 / 容量与设备量 / 电压与接入 / 桩型桩长与地勘 / 工期与里程碑 / 机械与人员配置。
- **整章删除**：与本项目不符的系统（升压站改造、线路跨越、储能、清淤等）。
- **新写专项**：本项目独有的工况（水上作业、保鱼保产、属地合规、特殊气候等）。

### 7.2 参考资料的三个坑

1. **规范清单全废**——旧版标书的规范号几乎必然有废止版本。
2. **项目参数全串**——容量、电压、地名、工期全是别的项目的。
3. **编号错乱、重复段落**——直接复制会把这些问题一起搬进来。

> **结论**：参考资料只提供「写法」和「结构」，**不提供任何事实**。事实只能来自招标文件、可研、现场情况、疑问。
